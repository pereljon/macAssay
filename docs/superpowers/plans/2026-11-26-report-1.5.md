# Report 1.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build macAssay 1.5 as designed in `dev/features/report-1.5.md`: one set of data files rendered as Markdown, JSON, OCSF, HTML, and CSV; run comparison; accepted risks; an exit status by severity; managed settings; unreadable evidence recorded as skips; the `+dev` version marker; and the fail-closed redaction fix.

**Architecture:** `macassay` is one Bash 3.2 script. The audit collects into four data files in `$TMP` (`meta.tsv`, `findings.tsv`, `skipped.tsv`, `body.md`). A new `render_all` normalizes, validates, and renders them. Remote mode moves the data files to the local Mac as a five-line bundle, and the local Mac renders. Pure functions live above the `MACASSAY_LIB` line, so `dev/test.sh` can call them on fixture folders.

**Tech Stack:** `/bin/bash` 3.2; stock macOS tools (`awk`, `sed`, `tr`, `iconv`, `plutil`, `defaults`, `base64`, `osascript -l JavaScript`); ShellCheck for linting (development only).

## Global Constraints

- Run under `/bin/bash` 3.2. Call only tools that ship with macOS. No `mapfile`, no associative arrays, no `${var,,}`, no `jq`.
- No new sudo rule, no new side effect, no new network traffic. `gen_rules` and every `priv` command stay unchanged.
- Every value from a data file is validated before use. No such value reaches shell arithmetic, `[[ ]]`, `eval`, or a path (design, Validation).
- Normalize before any format is written: `iconv -c -f UTF-8 -t UTF-8`, then `redact_ids` under `LC_ALL=C`. Write no report when either step fails.
- Escape text from the audited Mac with one function per format: `JSON.stringify` (JSON, OCSF), `html_esc` (HTML), `csv_field` (CSV).
- JXA scripts are fixed single-quoted strings with no `'` inside. They parse with `JSON.parse` only, never run input, and write only fixed file names in the render folder.
- Every `finding` call keeps a literal ID or `"$id"`. The optional fifth argument is `managed`, `local`, or a variable that holds one of them.
- Exit statuses: 0 finished, 1 error, 2 usage error, 3 an open finding reaches `--fail-on`.
- Use the project terms: a check is a test, a finding is a judged result, a flag is a command-line option. Write macAssay in prose, `macassay` for the command and files.
- Do not commit generated reports. Keep run output in `.scratch/report-1.5/`, which `.gitignore` already covers.
- Do not write the user's name or initials in any project file.
- Commit on `feature/report-1.5` only. Write each message to `.scratch/report-1.5/msg.txt`, end it with the `Co-Authored-By:` trailer of the model that wrote the change and no other trailer, and run `git commit -F .scratch/report-1.5/msg.txt` in its own Bash call.
- Before each commit, run `bash -n macassay`, `shellcheck macassay`, and `dev/test.sh`. The suite must pass. ShellCheck must show no finding beyond the baseline (Task 0).
- Keep the help text (the header comment in `macassay`) in step with the options in the same commit that changes an option.

# P16 (V1): VERSION follows the release rule against the latest v* tag. Only the version number counts, never the date.
ver_gt() { local a1 a2 a3 b1 b2 b3 re='^[0-9]+\.[0-9]+\.[0-9]+$'
  [[ $1 =~ $re ]] && [[ $2 =~ $re ]] || return 1
  IFS=. read -r a1 a2 a3 <<< "$1"; IFS=. read -r b1 b2 b3 <<< "$2"
  [ "$a1" -gt "$b1" ] && return 0; [ "$a1" -lt "$b1" ] && return 1

Replace `redact_ids` at `macassay:250` with:

```bash
redact_ids() { LC_ALL=C sed -E 's/[0-9A-Fa-f]{8}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{12}/<UUID>/g'; }
# normalize_file IN OUT: OUT is IN as valid UTF-8 with dashed UUIDs replaced. Fails, and leaves no OUT, when a step fails.
# iconv runs first: BSD sed stops at an invalid byte under a UTF-8 locale. Redaction runs second: iconv -c can join a split UUID.
normalize_file() {
  if iconv -c -f UTF-8 -t UTF-8 < "$1" > "$2.u" 2>/dev/null && redact_ids < "$2.u" > "$2"; then rm -f "$2.u"; return 0; fi
  rm -f "$2" "$2.u"; return 1; }
```

# load_accepted FILE: prints ID<TAB>MATCH<TAB>REASON for each entry in an accepted-risk file. The file is read as text,
# never run. A first word that GUIDANCE does not list fails the load, so a typo cannot accept nothing in silence.
load_accepted() { local line id rest match reason n=0
  [ -r "$1" ] || { echo "Cannot read the accepted-risk file: $1" >&2; return 1; }
  while IFS= read -r line || [ -n "$line" ]; do n=$((n + 1))
    line="${line#"${line%%[![:space:]]*}"}"
    case "$line" in ''|'#'*) continue ;; esac
    id="${line%%[[:space:]#]*}"; rest="${line#"$id"}"
    case "$rest" in *'#'*) reason="${rest#*#}"; match="${rest%%#*}" ;; *) reason=""; match="$rest" ;; esac
    known_id "$id" || { echo "Line $n of $1: $id is not a finding ID that macassay gives." >&2; return 1; }
    printf '%s\t%s\t%s\n' "$id" "$(printf '%s' "$match" | sed 's/^[[:space:]]*//' | clean_field)" "$(printf '%s' "$reason" | sed 's/^[[:space:]]*//' | clean_field)"
